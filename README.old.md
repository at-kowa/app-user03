# app-user03（情シス質問箱・技術検証）

要件は [docs/requirements.md](docs/requirements.md) を参照。

## 第1版（画面のみ・架空データ）

- ビルド不要の HTML／CSS／JavaScript で作っている（npm は使わない）
- データは `app/js/repositories/mock-data.js` の架空データ。再読み込みすると元に戻る
- データベース（supabase）につなぐときは `app/js/repositories/repository.js` の中身だけを差し替える

### 画面の開き方

1. エクスプローラーで `app/index.html` をダブルクリックし、Edge で開く
2. ログイン画面の「画面確認用のテストアカウント」から社員番号を選ぶ（第1版ではパスワードは確認しないので、何か入力すればログインできる）

| 社員番号 | 権限 | 確かめられること |
|---|---|---|
| 100001 | 一般 | 投稿・自分の投稿・FAQ |
| 100002 | 一般 | 初回ログイン時のパスワード変更 |
| 200001 / 200002 | 情シス担当 | 受付一覧・対応・FAQ 公開編集 |
| 300001 | 管理者 | 上記＋FAQ の削除 |
| 900001 | 無効 | ログインできないこと |

### フォルダ構成

```
app/
├─ index.html
├─ css/style.css
└─ js/
   ├─ util.js            … エスケープ・日付・画像縮小
   ├─ state.js           … ログイン中の利用者・自動ログアウト
   ├─ main.js            … 画面の切り替え・ヘッダー
   ├─ views/             … 画面ごとの処理
   └─ repositories/      … データアクセス（第1版は架空データ）
```
